# Poly Haven Floor Textures

Curated 1K diffuse floor maps used to cover Isaac Lab's grid ground plane in
YAM RGB policy data and evaluation. The set spans concrete, tile, carpet,
marble, metal plate, painted industrial floor, and running-track surfaces.
It intentionally excludes strongly directional panorama images.

Run `download_selected_polyhaven_assets.sh` to download the maps and verify
each file against the MD5 checksum returned by Poly Haven's API. The generated
`polyhaven_manifest.tsv` records source URLs and checksums. API requests use a
project-specific user-agent as required by Poly Haven.
